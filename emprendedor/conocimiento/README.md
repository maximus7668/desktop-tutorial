# Conocimiento

Lo que aprendo y no quiero olvidar. Cada afirmación con su fuente (enlace, fecha) o marcada como
hipótesis.

- `saturados.md`: mercados a evitar y por qué (con datos).
- `ideas.md`: ideas evaluadas, con sus números (coste de captar un cliente, precio, recuperación)
  y su estado (en estudio / validando / descartada / elegida).
- `experimentos.md`: cada experimento con criterio de fracaso, fecha límite y resultado.
